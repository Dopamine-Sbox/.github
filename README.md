# Dopamine-Sbox organization configuration

This repository provides the public Dopamine-Sbox organization profile and the
default contribution, support, security, issue, and pull-request guidance used
by organization repositories that do not define their own files.

The public organization profile is maintained in [`profile/README.md`](profile/README.md).

Repository-specific files take precedence over these defaults. Licenses are not
inherited from this repository and must be added to each project individually.
