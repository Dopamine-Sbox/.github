# Support

Use the affected repository's issue tracker for reproducible bugs and feature
requests. If Discussions are enabled, use them for setup questions, design
ideas, hardware comparisons, and other open-ended community help.

Before requesting support:

1. Read the repository README and troubleshooting documentation.
2. Search existing issues and discussions.
3. Reproduce the problem with the documented configuration when possible.
4. Collect the exact revision, environment, configuration, and redacted logs.

Do not publish access tokens, server tokens, passwords, private panel URLs,
private IP addresses, or personal information. Follow the
[security policy](SECURITY.md) for vulnerabilities and credential exposure.

Problems in the s&box engine or official packages should generally be reported
to [Facepunch/sbox-issues](https://github.com/Facepunch/sbox-issues). Problems in
our installation scripts, integrations, games, or documentation belong in the
corresponding Dopamine-Sbox repository.
