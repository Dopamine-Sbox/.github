## Public projects

| Project | Purpose |
| --- | --- |
| [Native Linux s&box dedicated-server guide](https://github.com/Dopamine-Sbox/sbox-dedi-setup-guide) | Reproducible bare-metal Ubuntu installation, lifecycle management, client-join validation, and troubleshooting for the public-source Linux server. |

We also collaborate with other s&box community projects, including the
[GameForge s&box Pterodactyl and Pelican egg](https://github.com/GameForgeGG/sbox-egg).

## What we work on

- dedicated-server deployment and lifecycle tooling;
- reproducible server benchmarks and compatibility testing;
- s&box games, editor tooling, and developer integrations;
- community services that connect s&box with other platforms.

## Contributing and support

Start with the README and issue tracker in the repository you are using. Bug
reports are most useful when they include the exact revision, operating system,
runtime, game package, reproduction steps, and redacted logs.

Please read our shared [contribution guidelines](https://github.com/Dopamine-Sbox/.github/blob/main/CONTRIBUTING.md),
[support guidance](https://github.com/Dopamine-Sbox/.github/blob/main/SUPPORT.md), and
[security policy](https://github.com/Dopamine-Sbox/.github/blob/main/SECURITY.md).
